How this page stays current

Nothing here depends on the Lenovo being on. A GitHub Actions cron job runs build.py on GitHub's servers, pulls every feed, and commits the rendered page back to the repo. GitHub Pages serves it. Your phone just loads a static file.

Zero JavaScript, on purpose

The tabs are CSS-only radio buttons. Gmail mobile strips <script>, so the same markup can be emailed without rendering blank — which is what happened to an earlier JS dashboard.

Add to your home screen

iPhone: open this URL in Safari, tap Share, then Add to Home Screen. The URL never changes, so the icon always opens the newest build.

Known data caveat

Sleeper's /rosters endpoint has been observed serving a stale preseason snapshot for Muppets. This builder reads rosters from the live /matchups feed instead.
